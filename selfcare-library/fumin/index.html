不眠

対象部位：全身・睡眠のリズム

はじめにお読みください

この資料は、一般的な健康情報として自宅でできるセルフケアの工夫を紹介するもので、医療行為ではありません。紹介する内容は、症状の改善や治療の効果を約束するものではありません。

不眠は、寝つきにくい、夜中に目が覚める、朝早く目覚めてしまうなど、眠りに関する悩みの総称です。この資料は睡眠薬などの代わりになるものではありません。就寝前の過ごし方や朝の光の浴び方など、眠りのリズムを整えるための生活習慣の工夫を、一般的な情報として紹介します。

1この症状で一般的に言われる要因

  • 就寝直前まで明るい画面を見続けると、眠気を促すホルモンのリズムが乱れやすいと言われています。
  • 昼寝が長すぎたり、夕方以降のカフェイン摂取が、夜の寝つきに影響する場合があるとされています。
  • 日中の活動量が少ない日は、体がほどよい疲れを感じにくい場合があると言われています。
  • 心配ごとやストレスで頭が冴えた状態が続くと、寝つきにくくなる場合があるとされています。

対象となる部位は図8-1に示します。

2自宅でできるセルフケアの手順

中心となる動きの様子は図8-2に示します。どの手順も、痛みがあるときは無理をせず中止してください。

  1. 1朝、光を浴びて体内時計を合わせる

    起きたらカーテンを開け、朝の光を浴びます。体内時計は光で調整されると言われており、夜の眠気のリズムにもつながるとされています。

  2. 2就寝1時間前は画面を離れる

    図8-2のように、寝る前は照明を少し落とし、読書や音楽など静かな過ごし方に切り替えます。スマートフォンは寝室の外に置くか、おやすみモードにします。

  3. 3ぬるめのお湯に浸かる

    就寝の1〜2時間前に、38〜40℃のぬるめのお湯に15分ほど浸かります。入浴後に体温が下がっていく過程で眠気を感じやすいと言われています。

  4. 4ゆっくりした呼吸で体をゆるめる

    あお向けになり、4秒かけて息を吸い、6〜8秒かけてゆっくり吐く呼吸を数分行います。吐く息を長くすると、体がリラックスしやすいと言われています。図8-1の全身の力を抜いていく意識で行います。

3やってはいけないこと・注意

  • 眠れないからと寝酒を習慣にしないでください。眠りが浅くなる場合があると言われています。
  • 眠くないのに無理に布団に入り続けず、一度起きて静かに過ごす方法もあるとされています。
  • 他人の睡眠薬を譲り受けて使うことは絶対にしないでください。

4医療機関への受診をすすめる目安

次のような場合は、セルフケアより先に医療機関へ相談してください。

  • 不眠が数週間以上続き、日中の生活に支障が出ている場合
  • いびきが大きく、呼吸が止まっていると指摘されたことがある場合
  • 眠れないことに加え、気分の落ち込みが強く続く場合
  • 夜中に脚がむずむずして眠れない状態が繰り返す場合

5サロンでできること

サロンでは、夕方の時間帯に体をゆっくりほぐす施術をご用意しています。施術の後はそのまま静かに過ごせるよう、夜の予定を詰めすぎない日にお越しいただくのもおすすめの過ごし方です。眠りの治療を目的としたものではありません。

サロンのご案内：ステラポラリス（梅田）／北辰堂（ステラポラリスは近日開院予定・ご予約の受付は開院後）

最後に

繰り返しになりますが、この資料は医療行為ではなく、診断や治療の代わりにはなりません。症状が続く場合、強くなる場合、少しでも不安がある場合は、セルフケアを続ける前に医療機関へ相談してください。

ポプリ
