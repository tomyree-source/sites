便秘

対象部位：お腹・腸

はじめにお読みください

この資料は、一般的な健康情報として自宅でできるセルフケアの工夫を紹介するもので、医療行為ではありません。紹介する内容は、症状の改善や治療の効果を約束するものではありません。

便秘は、排便の回数が少ない、便が硬い、出にくいといった状態の総称で、生活習慣との関わりが大きいと言われています。この資料では、腸の動きを助けるとされる日常の習慣（食事、水分、運動、トイレの姿勢）と、お腹のやさしいマッサージを紹介します。長く続く便秘や、便の色の異常などは病気のサインの場合もあるため、受診の目安もご確認ください。

1この症状で一般的に言われる要因

  • 食物繊維や水分の不足は、便が硬くなりやすい一因になると言われています。
  • 運動不足が続くと、腸の動きも弱くなりやすいとされています。
  • 排便のタイミングを我慢する習慣が続くと、便意を感じにくくなる場合があると言われています。
  • ストレスや生活リズムの乱れ、薬の影響などが関係する場合もあるとされています。

対象となる部位は図13-1に示します。

2自宅でできるセルフケアの手順

中心となる動きの様子は図13-2に示します。どの手順も、痛みがあるときは無理をせず中止してください。

  1. 1朝、水を飲んで腸を起こす

    起きてすぐにコップ一杯の水を飲み、朝食を抜かずにとります。胃に食べ物が入ることで腸が動き出す反射があると言われています。

  2. 2お腹を「の」の字にやさしくなでる

    あお向けに寝て、両手のひらでお腹を時計回りに大きな円を描くようにゆっくりなでます。図13-2のように、腸の流れの向きに沿う動きとされています。図13-1のお腹の範囲を、1回3分ほど、強く押さずに行います。

  3. 3トイレでは足台を使う

    洋式トイレでは、足元に台を置いて膝を少し高くすると、排便しやすい姿勢になると言われています。いきみすぎず、時間を決めて座ります。

  4. 4食後に軽く歩く

    食後15分ほど、ゆっくり歩きます。体を動かすことが腸の動きを助けると言われています。

3やってはいけないこと・注意

  • 下剤を自己判断で長期間使い続けないでください。使い方は医師や薬剤師に相談するのが安全です。
  • お腹を強く押したり、長時間いきんだりしないでください。
  • 極端な食事制限で無理に体重を落とそうとしないでください。

4医療機関への受診をすすめる目安

次のような場合は、セルフケアより先に医療機関へ相談してください。

  • 便に血が混じる、便の色が黒い場合
  • 便秘と下痢を繰り返すようになった、便が急に細くなった場合
  • 強い腹痛や嘔吐、お腹の張りが続く場合
  • 理由のない体重減少を伴う場合

5サロンでできること

サロンでは、腹部への施術はご希望と体調を確認したうえで、やさしい圧の範囲で行っています。お腹の不調の治療を目的としたものではありませんが、全身のリラックスと合わせてご相談ください。

最後に

繰り返しになりますが、この資料は医療行為ではなく、診断や治療の代わりにはなりません。症状が続く場合、強くなる場合、少しでも不安がある場合は、セルフケアを続ける前に医療機関へ相談してください。

ポプリ
