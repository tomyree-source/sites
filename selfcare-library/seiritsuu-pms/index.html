生理痛・PMS

対象部位：下腹部・骨盤

はじめにお読みください

この資料は、一般的な健康情報として自宅でできるセルフケアの工夫を紹介するもので、医療行為ではありません。紹介する内容は、症状の改善や治療の効果を約束するものではありません。

生理痛やPMS（月経前症候群）は、月経の周期に伴って現れる体の変化で、その強さには個人差が大きいと言われています。この資料では、つらい時期を少しでも穏やかに過ごすための、温め方や休息の取り方といった生活の工夫を紹介します。痛みが強い場合や、生活に支障がある場合は、婦人科への相談が大切です。

1この症状で一般的に言われる要因

  • 月経の前後にはホルモンのバランスが変化し、それに伴って体の不調を感じやすい時期があると言われています。
  • 下腹部や腰の冷えは、痛みを強く感じる一因になる場合があるとされています。
  • ストレスや睡眠不足が続くと、PMSの症状を強く感じる場合があると言われています。
  • 締め付けの強い衣服や、長時間の同じ姿勢も、骨盤まわりのめぐりを妨げる場合があるとされています。

対象となる部位は図10-1に示します。

2自宅でできるセルフケアの手順

中心となる動きの様子は図10-2に示します。どの手順も、痛みがあるときは無理をせず中止してください。

  1. 1下腹部と腰を温める

    カイロや湯たんぽを下腹部と腰の両方に当て、図10-2のように20分ほど温めます（低温やけどに注意し、肌に直接当て続けないでください）。温めることで過ごしやすくなる方が多いと言われています。

  2. 2骨盤まわりをゆっくり揺らす

    あお向けで膝を立て、両膝をそろえて左右へ小さく倒します。図10-1の骨盤まわりを無理のない範囲で動かし、痛みがあるときは中止します。

  3. 3予定を詰め込まない

    つらい時期は、できる範囲で予定を軽くし、早めに休む計画を立てます。「この時期は無理をしない」と決めておくこと自体が、負担を減らす工夫の一つです。

  4. 4温かい飲み物と軽い食事

    冷たい飲み物を控えめにし、温かい飲み物を選びます。食事は抜かず、少量ずつでも規則正しくとることが大切だと言われています。

3やってはいけないこと・注意

  • 痛みを我慢し続けて仕事や学校を無理にこなさないでください。痛み止めの使い方や受診も含め、早めの相談が大切です。
  • つらい時期の激しい運動や、冷水浴など体を冷やす行為は避けてください。
  • 市販薬を使う場合は用法・用量を守り、効きにくいと感じたら自己判断で量を増やさないでください。

4医療機関への受診をすすめる目安

次のような場合は、セルフケアより先に医療機関へ相談してください。

  • 市販の痛み止めを使っても痛みが治まらず、日常生活に支障がある場合
  • 月経の量が急に増えた、大きな血の塊が多く出る、貧血の症状がある場合
  • 月経でない時期にも下腹部の痛みが続く場合
  • 痛みが年々強くなっている場合

5サロンでできること

サロンでは、腹部へ直接強い圧をかけることはせず、お腹や腰を温めながら脚や背中をゆっくりほぐす対応が可能です。月経中でも受けられる内容がありますので、ご予約の際に体調をお知らせください。

サロンのご案内：ステラポラリス（梅田）／北辰堂（ステラポラリスは近日開院予定・ご予約の受付は開院後）

最後に

繰り返しになりますが、この資料は医療行為ではなく、診断や治療の代わりにはなりません。症状が続く場合、強くなる場合、少しでも不安がある場合は、セルフケアを続ける前に医療機関へ相談してください。

ポプリ
