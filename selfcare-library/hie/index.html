冷え

対象部位：手足・全身

はじめにお読みください

この資料は、一般的な健康情報として自宅でできるセルフケアの工夫を紹介するもので、医療行為ではありません。紹介する内容は、症状の改善や治療の効果を約束するものではありません。

冷えは、手足の先やお腹などが冷たく感じられる状態で、季節を問わず悩む人が多いと言われています。体温そのものは正常でも、血のめぐりや筋肉量、生活習慣などが関係して冷たく感じる場合があるとされています。この資料では、体を温める日常の工夫と、筋肉を動かす簡単な運動を紹介します。

1この症状で一般的に言われる要因

  • 筋肉は体の中で熱を作る働きがあり、運動不足で筋肉を使う機会が減ると、熱を作る力が落ちやすいと言われています。
  • 薄着や冷房の効いた環境、冷たい飲み物のとりすぎなども、体が冷えやすい条件になるとされています。
  • きつい衣服や長時間の同じ姿勢は、血のめぐりを妨げる場合があると言われています。
  • 睡眠不足や食事を抜く生活は、体温のリズムを整える力を弱める場合があるとされています。

対象となる部位は図6-1に示します。

2自宅でできるセルフケアの手順

中心となる動きの様子は図6-2に示します。どの手順も、痛みがあるときは無理をせず中止してください。

  1. 1ふくらはぎを動かす

    椅子につかまって立ち、かかとをゆっくり上げ下げします。ふくらはぎは「第二の心臓」とも呼ばれ、足先の血のめぐりを助けるポンプの役割があるとされています。10回を目安に行います。

  2. 2手足の指をグーパーする

    手の指と足の指を、握って開く動きをゆっくり20回ほど繰り返します。図6-1の手足の末端を動かすことで、指先まで意識を向けるきっかけになります。

  3. 3足湯で足元から温める

    洗面器に40℃前後のお湯を入れ、図6-2のように足首まで10〜15分ほど浸します。熱すぎるお湯は避け、途中で温度が下がったら差し湯をします。

  4. 4お腹と首まわりを冷やさない

    腹巻きやストールなどを使い、お腹と首を冷気から守ります。大きな血管が通る場所を冷やさない工夫として知られています。

3やってはいけないこと・注意

  • 熱いお湯での長風呂は、のぼせや脱水の原因になることがあります。温度と時間を守ってください。
  • 冷えた手足を直接熱源に当て続けると、低温やけどのおそれがあります。
  • 締め付けの強い靴下や衣服で血のめぐりを妨げないようにしてください。

4医療機関への受診をすすめる目安

次のような場合は、セルフケアより先に医療機関へ相談してください。

  • 片側の手足だけが急に冷たくなる、色が白や紫に変わる場合
  • 冷えとともに強い痛みやしびれが続く場合
  • 体重の急な変化、異常なだるさを伴う冷えが続く場合
  • 糖尿病などで足の感覚が鈍い方が足に傷や変色を見つけた場合

5サロンでできること

サロンでは、温かいオイルを使ったトリートメントで体全体に触れていく時間をご用意しています。施術後は体が温まりやすい状態と言われていますので、そのまま冷やさない服装でお越しください。

サロンのご案内：ステラポラリス（梅田）／北辰堂（ステラポラリスは近日開院予定・ご予約の受付は開院後）

最後に

繰り返しになりますが、この資料は医療行為ではなく、診断や治療の代わりにはなりません。症状が続く場合、強くなる場合、少しでも不安がある場合は、セルフケアを続ける前に医療機関へ相談してください。

ポプリ

冷える日は、温かい飲み物を用意して、ゆっくり読み進めてください。
