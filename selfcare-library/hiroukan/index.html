疲労感

対象部位：全身

はじめにお読みください

この資料は、一般的な健康情報として自宅でできるセルフケアの工夫を紹介するもので、医療行為ではありません。紹介する内容は、症状の改善や治療の効果を約束するものではありません。

疲労感は、体を動かした後の自然な感覚である一方、休んでも抜けないだるさが続く場合は、生活習慣の見直しや体の病気の確認が必要なこともあります。この資料では、疲れをため込みにくい日常のリズムの作り方と、その場でできる小さなリフレッシュ方法を紹介します。

1この症状で一般的に言われる要因

  • 睡眠の量と質が足りていないことは、疲労感の代表的な背景の一つと言われています。
  • 食事の量が不足していたり、偏っていたりすると、体を動かすエネルギーが不足しやすいとされています。
  • 運動不足の状態では、少しの活動でも疲れやすく感じると言われています。
  • 長時間の緊張や、人間関係などの精神的な負担も、体の疲れとして感じられる場合があると言われています。

対象となる部位は図15-1に示します。

2自宅でできるセルフケアの手順

中心となる動きの様子は図15-2に示します。どの手順も、痛みがあるときは無理をせず中止してください。

  1. 115分以内の短い昼寝

    昼食後の早い時間に、椅子にもたれて15分ほど目を閉じます。長く寝すぎると夜の眠りに影響する場合があるため、時間を決めて行います。

  2. 2軽い散歩で気分を切り替える

    図15-2のように、屋外を10〜15分ほど歩きます。外の光や空気に触れることが、気分の切り替えにつながると言われています。

  3. 3全身を伸ばすストレッチ

    両手を天井へ伸ばし、体側を左右に伸ばします。図15-1のように全身を大きく使う動きで、固まった体をゆるめます。

  4. 4休む予定を先に入れる

    予定表に仕事や家事だけでなく、休息の時間も先に書き込みます。疲れてから休むのではなく、疲れをためないための計画的な休息が大切だと言われています。

3やってはいけないこと・注意

  • 疲れをごまかすためにカフェインやエナジードリンクに頼りすぎないでください。
  • 疲労感が強いときの激しい運動は避け、回復を優先してください。
  • 休んでも回復しない疲れを「年齢のせい」と放置しないでください。

4医療機関への受診をすすめる目安

次のような場合は、セルフケアより先に医療機関へ相談してください。

  • 十分休んでも疲労感が数週間以上続く場合
  • 疲労感に加えて、発熱、体重減少、息切れなどがある場合
  • 気分の落ち込みが強く、何にも興味が持てない状態が続く場合
  • 貧血のようなふらつきや動悸を伴う場合

5サロンでできること

サロンでは、全身のオイルトリートメントで体をゆっくりほぐし、何もしないで横になる休息の時間をご用意しています。疲労の原因を診断する場所ではありませんが、日々のケアの一つとしてご利用ください。

サロンのご案内：ステラポラリス（梅田）／北辰堂（ステラポラリスは近日開院予定・ご予約の受付は開院後）

最後に

繰り返しになりますが、この資料は医療行為ではなく、診断や治療の代わりにはなりません。症状が続く場合、強くなる場合、少しでも不安がある場合は、セルフケアを続ける前に医療機関へ相談してください。
