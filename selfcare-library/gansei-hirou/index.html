眼精疲労

対象部位：目・眉間まわり

はじめにお読みください

この資料は、一般的な健康情報として自宅でできるセルフケアの工夫を紹介するもので、医療行為ではありません。紹介する内容は、症状の改善や治療の効果を約束するものではありません。

眼精疲労は、目を使う作業のあとに目の重さやかすみ、眉間の圧迫感などを感じる状態の呼び方です。画面を見る時間が長くなった現代では、多くの人が心当たりのある不調と言われています。この資料では、目のまわりの筋肉を休ませる工夫と、作業環境の見直し方を紹介します。

1この症状で一般的に言われる要因

  • 画面を長時間見続けると、まばたきの回数が減り、目の表面が乾きやすくなると言われています。
  • 近くを見続けることで、目のピント調節をする筋肉が働きっぱなしになり、疲れがたまりやすいとされています。
  • 画面の明るさと部屋の明るさの差が大きい環境や、反射の強い画面も目の負担になる場合があると言われています。
  • 度の合わない眼鏡やコンタクトレンズの使用も、目が余分に頑張る原因になる場合があるとされています。

対象となる部位は図5-1に示します。

2自宅でできるセルフケアの手順

中心となる動きの様子は図5-2に示します。どの手順も、痛みがあるときは無理をせず中止してください。

  1. 1遠くを見る休憩をはさむ

    20分ほど画面を見たら、20秒ほど窓の外など遠くを見る習慣をつけます。ピント調節の筋肉を休ませる工夫として知られています。

  2. 2手のひらで目を覆う（パーミング）

    両手をこすり合わせて温め、図5-2のように目を閉じた上から手のひらでやさしく覆い、1分ほど暗さの中で休みます。眼球を押さないよう、手のひらを少しくぼませるのがコツです。

  3. 3目のまわりを温める

    温めたタオルを閉じた目の上に5分ほど置きます。図5-1の目のまわりには細かな筋肉があり、温めることで緊張がゆるみやすいと言われています。

  4. 4まばたきと姿勢を意識する

    意識してゆっくりまばたきを数回行い、涙で目をうるおします。画面は目から40cm以上離し、目線が少し下向きになる位置が目安とされています。

3やってはいけないこと・注意

  • 目を強くこすったり、眼球を上から押したりしないでください。
  • 暗い部屋で明るい画面を長時間見ることは避けてください。
  • 目の疲れをごまかすために、目薬を用法以上に頻繁に使わないでください。

4医療機関への受診をすすめる目安

次のような場合は、セルフケアより先に医療機関へ相談してください。

  • 視力が急に落ちた、物が二重に見える、視野の一部が欠ける場合
  • 目の強い痛みや充血、光がまぶしくて目が開けられない場合
  • 十分休んでも数日以上つらさが続く場合
  • 頭痛や吐き気を伴う目の疲れが繰り返し起きる場合

5サロンでできること

サロンでは、目元からこめかみ、頭皮までをゆっくりほぐすケアをご用意しています。画面作業で固まりやすい首や肩と合わせて、目を閉じて過ごす休息の時間としてご利用ください。

サロンのご案内：ステラポラリス（梅田）／北辰堂（ステラポラリスは近日開院予定・ご予約の受付は開院後）

最後に

繰り返しになりますが、この資料は医療行為ではなく、診断や治療の代わりにはなりません。症状が続く場合、強くなる場合、少しでも不安がある場合は、セルフケアを続ける前に医療機関へ相談してください。

ポプリ

目が疲れたら、遠くをぼんやり眺めるひと休みを。ポプリもよく窓の外を眺めています。
