ストレス・自律神経の乱れ

対象部位：全身・自律神経

はじめにお読みください

この資料は、一般的な健康情報として自宅でできるセルフケアの工夫を紹介するもので、医療行為ではありません。紹介する内容は、症状の改善や治療の効果を約束するものではありません。

「自律神経の乱れ」は病名ではなく、緊張と休息の切り替えがうまくいかず、だるさや動悸、ほてりなどさまざまな不調を感じやすい状態を指す日常的な表現です。この資料では、緊張をゆるめる方向へ体のスイッチを切り替えるための、呼吸や生活リズムの工夫を紹介します。症状が強い場合は、まず医療機関での相談が大切です。

1この症状で一般的に言われる要因

  • 自律神経は活動時の「交感神経」と休息時の「副交感神経」がバランスを取って働くとされており、緊張が続くと切り替えがうまくいきにくくなると言われています。
  • 睡眠不足や不規則な食事、長時間の画面作業なども、このバランスに影響する場合があるとされています。
  • 季節の変わり目や気圧の変化に体の不調を感じやすい人もいると言われています。
  • 頑張りすぎる生活が続き、意識して休む時間が取れていないことも一因になるとされています。

対象となる部位は図9-1に示します。

2自宅でできるセルフケアの手順

中心となる動きの様子は図9-2に示します。どの手順も、痛みがあるときは無理をせず中止してください。

  1. 1吐く息を長くする呼吸法

    楽な姿勢で座り、鼻から4秒吸って、口から8秒かけて細く長く吐きます。図9-2の呼吸のリズムを目安に、5分ほど続けます。吐く息を長くすると副交感神経が働きやすいと言われています。

  2. 2朝と夜のリズムをそろえる

    起きる時刻と寝る時刻をできるだけ一定にし、朝は光を浴び、夜は照明を落とします。一日のリズムが自律神経の切り替えを助けるとされています。

  3. 3温かい飲み物で一息つく

    白湯やハーブティーなど温かい飲み物を、作業の区切りにゆっくり飲みます。「休む」という意識の切り替え自体が、緊張をゆるめるきっかけになると言われています。

  4. 4軽い運動を日課にする

    図9-1のように全身を大きく使う散歩を、1日15〜20分ほど取り入れます。激しい運動ではなく、会話ができる程度の速さが目安とされています。

3やってはいけないこと・注意

  • 不調を「気のせい」と我慢し続けないでください。体の病気が隠れている場合もあります。
  • エナジードリンクなどで無理に気分を上げようとしないでください。
  • 自己判断でサプリメントや漢方を重ねて使わないでください。医師や薬剤師への相談が安全です。

4医療機関への受診をすすめる目安

次のような場合は、セルフケアより先に医療機関へ相談してください。

  • 動悸や息苦しさ、胸の痛みが繰り返し起こる場合
  • 気分の落ち込みや不安が強く、日常生活が回らなくなってきた場合
  • めまいや失神、手足のしびれを伴う場合
  • 不調が数週間以上続いている場合

5サロンでできること

サロンでは、静かな空間でゆっくりした圧のトリートメントを行い、体を休める方向へ切り替える時間をご用意しています。医療行為ではありませんが、「何もしないで休む時間」としてご利用いただけます。

サロンのご案内：ステラポラリス（梅田）／北辰堂（ステラポラリスは近日開院予定・ご予約の受付は開院後）

最後に

繰り返しになりますが、この資料は医療行為ではなく、診断や治療の代わりにはなりません。症状が続く場合、強くなる場合、少しでも不安がある場合は、セルフケアを続ける前に医療機関へ相談してください。
