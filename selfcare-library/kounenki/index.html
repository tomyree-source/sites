更年期の不調

対象部位：全身・ホルモンの変化

はじめにお読みください

この資料は、一般的な健康情報として自宅でできるセルフケアの工夫を紹介するもので、医療行為ではありません。紹介する内容は、症状の改善や治療の効果を約束するものではありません。

更年期は、閉経をはさむ前後およそ10年ほどの時期を指し、ホルモンの変化に伴って、ほてりや発汗、気分の波などさまざまな不調を感じる方がいる時期と言われています。不調の現れ方は人によって大きく異なります。この資料では、日常生活のなかで取り入れやすい工夫を紹介します。治療が必要な症状もあるため、受診の目安もあわせてご確認ください。

1この症状で一般的に言われる要因

  • 女性ホルモンの分泌がゆらぎながら減っていく過程で、自律神経の働きにも影響が出やすい時期だと言われています。
  • ほてりやのぼせ（ホットフラッシュと呼ばれる症状）は、この時期によく聞かれる変化の一つとされています。
  • 睡眠の質の変化や、気分の落ち込み・イライラを感じやすくなる方もいると言われています。
  • 加齢に伴う筋肉量の低下や骨の変化も、この時期と重なって進みやすいとされています。

対象となる部位は図11-1に示します。

2自宅でできるセルフケアの手順

中心となる動きの様子は図11-2に示します。どの手順も、痛みがあるときは無理をせず中止してください。

  1. 1重ね着で温度調整しやすくする

    ほてりを感じたときにすぐ脱ぎ着できる服装にし、首元を開けられる工夫をします。図11-2のような扇子や冷感グッズを携帯する方もいます。

  2. 2軽い筋力運動を取り入れる

    椅子を使ったスクワットやかかと上げなど、無理のない運動を週に数回行います。筋肉と骨への刺激は、この時期の体力維持に大切だと言われています。

  3. 3眠りの環境を整える

    寝室の温度と湿度を心地よく保ち、寝具は吸湿性のある素材を選びます。発汗で目覚める場合は、着替えを枕元に用意しておくと安心です。

  4. 4不調を記録する

    ほてりの起きた時刻、眠りの様子、気分の変化などを手帳やアプリに簡単に記録します。図11-1のように全身に関わる変化だからこそ、記録は受診のときにも役立つ情報になります。

3やってはいけないこと・注意

  • 「年齢のせい」と決めつけて不調を我慢し続けないでください。治療で対応できる症状もあります。
  • 根拠のあいまいな高額な商品や健康法に頼りすぎないでください。
  • 骨の健康に関わるため、極端な食事制限は避けてください。

4医療機関への受診をすすめる目安

次のような場合は、セルフケアより先に医療機関へ相談してください。

  • 閉経後に再び出血があった場合
  • 気分の落ち込みが強く、日常生活や仕事に支障が出ている場合
  • 動悸や息切れ、胸の不快感が繰り返す場合
  • 体重の急な減少や、異常な発汗が続く場合

5サロンでできること

サロンでは、温度調整のしやすい静かな環境で、体の緊張をゆるめるトリートメントをご用意しています。更年期の治療を行う場所ではありませんが、ご自身の体と向き合う休息の時間としてご利用いただけます。体調に合わせて施術内容は調整しますので、遠慮なくお声がけください。

サロンのご案内：ステラポラリス（梅田）／北辰堂（ステラポラリスは近日開院予定・ご予約の受付は開院後）

最後に

繰り返しになりますが、この資料は医療行為ではなく、診断や治療の代わりにはなりません。症状が続く場合、強くなる場合、少しでも不安がある場合は、セルフケアを続ける前に医療機関へ相談してください。

ポプリ
